# kr3-responsive-shop

## Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Описание

Учебный интернет-магазин ShopProject. Основа проекта перенесена из контрольной работы №1
(HTML/CSS без фреймворков) и будет адаптирована под разные размеры экранов.

## Структура проекта

- `index.html` — главная страница: hero-блок, преимущества, популярные товары;
- `catalog.html` — каталог с фильтром;
- `product.html` — карточка товара и таблица характеристик;
- `order.html` — форма заявки;
- `contacts.html` — контакты и форма обратной связи;
- `css/style.css` — базовые стили проекта;
- `css/responsive.css` — адаптивные стили (Mobile First);
- `js/main.js` — бургер-меню и открытие/закрытие модального окна;
- `images/` — изображения;
- `README.md` — описание проекта.

## Адаптивные решения

- Добавлен файл `css/responsive.css`, подключён на всех страницах после `style.css`,
  чтобы адаптивные правила переопределяли базовые.
- На всех страницах есть `meta viewport`.
- Применён подход **Mobile First**: базовые стили написаны для мобильного экрана,
  расширения для больших экранов добавляются медиазапросами `min-width`.
- Из `style.css` убраны фиксированные колонки сеток (`grid-template-columns`),
  раскладка задаётся в `responsive.css`.
- Для изображений и видео задано `max-width: 100%` и `height: auto`.
- Для всех элементов задано `box-sizing: border-box`.
- Отступы контейнеров (`main`, шапка, подвал): 16px на мобильном, 24px с 768px.
  Края шапки, содержимого и подвала совпадают.

### Навигация

- На мобильном экране меню скрыто за бургер-кнопкой. Логотип и кнопка стоят в одной
  строке, меню раскрывается под ними столбиком (`flex-wrap: wrap` + `flex-basis: 100%`).
- Пункты меню занимают всю ширину и имеют высоту не меньше 44px, чтобы их было
  удобно нажимать пальцем.
- С 768px бургер скрыт, меню выводится в строку (`flex-direction: row`, `flex-wrap: wrap`).
- Шапка закрепляется при прокрутке (`position: sticky`) только с 768px.
  На мобильном она обычная, чтобы не закрывать содержимое экрана.

## Доступность

- Бургер-меню сделано на элементе `<button type="button">`, поэтому работает
  с клавиатуры (Tab, Enter, пробел).
- У кнопки есть `aria-label` («Открыть меню» / «Закрыть меню»), `aria-controls`
  со ссылкой на список меню и `aria-expanded`, который JavaScript меняет
  на `true`/`false` при открытии и закрытии.
- Полоски иконки скрыты от скринридеров через `aria-hidden="true"`.
- У бургер-кнопки есть видимый фокус (`:focus-visible`).

## Самостоятельные доработки

- **Бургер-меню для мобильных экранов.** Меню открывается и закрывается кнопкой,
  иконка анимированно превращается из ☰ в ✕ через селектор по атрибуту
  `[aria-expanded="true"]`. Логика в `js/main.js`: переключение класса `is-open`
  через `classList.toggle()` и обновление `aria-expanded`.
